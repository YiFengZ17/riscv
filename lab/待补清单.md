报告里的图不是整窗口截图，而是从原截图裁出的相关部分，由下面的脚本生成到 `images/report/`：

```bash
python3 lab/report-tools/make-figures.py
```

如果重新截了图，先运行这个脚本，再运行 `build.sh`。
