# 实验报告待补清单

报告正文在 `实验报告.md`。生成流程是：先由它生成 LaTeX 源文件 `实验报告.tex`，再用 XeLaTeX 编译成 `实验报告.pdf`。**修改时只改 md**，因为 tex 每次都会重新生成，直接改 tex 的内容会被覆盖。按下面的顺序补完后，重新生成 PDF：

```bash
lab/report-tools/build.sh
```

也可以让 Claude 帮你重新生成。自己生成需要 pandoc 和带 ctex 的 TeX Live，所需的包写在 `build.sh` 开头。PDF 里还没补的截图很好认：截图位置是一个红框，框里写着该放的文件名。

## 二、截图

所有截图都放进 `lab/images/`，**文件名必须和下表完全相同**（png 格式），生成 PDF 时会自动插入对应位置。

通用操作：
1. 截哪一组，就先把 `first_case` 和 `last_case` 都改成这个编号，再 Assemble。
2. 在 Execute 窗口的 Text Segment 里，勾选对应指令那一行的 Bkpt 设断点，然后点 Run。
3. 程序停在断点时，这条指令**还没有执行**。再点一次 Run，就会停到下一次断点。

如果截图里的值和下表“应看到”一栏不同，先检查断点位置和所选用例。确认没错的话，以截图为准，并修改报告里对应的表格和说明文字。
