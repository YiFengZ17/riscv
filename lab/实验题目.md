# 实验任务书：基于 RISC-V 的 1024 位无符号整数运算

课程：计算机系统原理  
实验平台：RARS 1.6，RV32 模式  
版本：2026-09-21（1024 位四则运算，自主编程版）

## 一、实验目标

完成本实验后，应能够：

1. 用多个 32 位字表示和处理 1024 位无符号整数。
2. 正确实现多字加减法中的进位、借位与无符号比较。
3. 实现多字乘法和整数除法，并说明算法正确性与执行次数。
4. 遵守 RISC-V 函数调用约定，利用寄存器和内存完成计算。
5. 使用边界测试和单步记录解释程序行为。

## 二、实验任务

从空白文件开始，自行编写可在 RARS 中独立汇编、运行的 `bigint1024.s`。程序须包含数据区、主程序 `main`、**add1024、sub1024、mul1024、div1024 四个运算子程序**及必要的辅助子程序，完成固定宽度的无符号加法、减法、乘法和整数除法。整数除法同时产生商与余数，不要求输入恰好整除。

本实验不采用教师代码模板填空。数据定义、缓冲区分配、函数调用、结果保存及测试组织均由学生完成，提交程序不得依赖教师提供的源代码或测试入口。

输入允许直接定义在数据区，不强制使用键盘输入；和、差、积、商、余数及三个状态值（carry、borrow、status）必须保存在有明确标签的内存区域，便于检查。可自行增加结果打印，但不要求编写 1024 位十进制字符串转换程序。

## 三、数据与接口规范

### 3.1 数据表示

每个操作数由连续的 **32 个 32 位字**组成，占 **128 字节**。设第 i 个字为 A[i]，则：

`A = Σ A[i] × 2^(32i)，i = 0, 1, …, 31。`

A[0] 为最低字，A[31] 为最高字，按低字在前存放。每个字按无符号数解释，缓冲区首地址按 4 字节对齐。输入范围为 `0 ≤ A,B ≤ 2^1024−1`。

和 S、差 D、商 Q、余数 R 各为 1024 位，使用 32 个字、128 字节。**乘积 P 为完整的 2048 位，使用 64 个字、256 字节**，同样按低字在前存放；P[0] 为最低字，P[63] 为最高字。

A、B 和各输出缓冲区由调用者分配，均互不重叠；不要求支持原地运算。不得修改输入，不得越界访问。返回时必须写出规定的全部输出字，不能依赖缓冲区初值为零。

### 3.2 函数接口

下表中的 `&X` 表示缓冲区 X 的首地址。

| 函数 | 入口参数 | 输出缓冲区 | a0 返回值 |
|---|---|---|---|
| add1024 | a0=&A，a1=&B，a2=&S | S=(A+B) mod 2^1024 | 溢出时 1，否则 0 |
| sub1024 | a0=&A，a1=&B，a2=&D | D=(A−B) mod 2^1024 | A<B 时 1，否则 0 |
| mul1024 | a0=&A，a1=&B，a2=&P | P=A×B，保存完整 2048 位乘积 | 正常完成返回 0 |
| div1024 | a0=&A，a1=&B，a2=&Q，a3=&R | B≠0 时 Q=floor(A/B)，R=A−B×Q | B≠0 时 0，B=0 时 1 |

补充约定：

- 加法溢出即 `A+B ≥ 2^1024`，仍须写出和的低 1024 位。
- 减法下溢输出模 2^1024 的无符号结果，不输出负号。
- 乘法必须写出 P 的全部 64 个字，包括为零的高位；不得仅保留低 1024 位。2048 位足以容纳任意两个合法输入的乘积，因此不另设乘法溢出标志。
- 除数非零时，商和余数必须满足 `A=B×Q+R` 且 `0≤R<B`。
- **除数为零时，Q、R 各自的全部 128 字节必须清零**，并返回 1；不得死循环。

### 3.3 调用约定

允许修改 a0–a7、t0–t6。使用 s0–s11 必须保存并恢复；返回时 sp 与入口值一致，栈帧保持 16 字节对齐。调用其他子程序时须保护 ra。除规定的输出缓冲区及合法栈空间外，不得产生额外内存写入；函数应能在一次执行中被重复调用。

程序必须提供 `main` 以及四个运算子程序的同名全局标签。主程序负责准备参数、调用函数并保存结果；算术子程序内不得使用 ecall。主程序或独立的输入输出辅助子程序可使用 ecall 打印或正常退出。

## 四、实现限制

1. 算术核心只使用 RV32I 整数指令，允许 li、la、mv、j、ret 等伪指令。
2. 禁止 mul、mulh、mulhu、mulhsu、div、divu、rem、remu，禁止浮点运算、宿主语言代算或使用预先计算的答案表。
3. 乘法须使用移位累加或其他有效的多字算法；不接受将 A 连续相加 B 次、循环次数随操作数数值线性增加的方案。禁止直接使用硬件乘法指令。
4. 除法须使用按位长除法或其他有效的多字算法；不接受仅反复减去 B、循环次数随商值线性增加的方案。
5. 输入输出和程序退出使用的 ecall 不属于算术核心，不得借助环境调用代算大整数运算。

## 五、正确性样例与验收

以下 10 组为必测数据，均为十进制或数学表达式。记 `M=2^1024−1`、`C=2^700+123456789`。学生须自行将输入组织为规定的 32 字布局，并将实际结果与下表比较；表中表达式是数值定义，不是可直接粘贴的汇编代码。

| 编号 | A | B | 和 S / carry | 差 D / borrow | 完整乘积 P | 商 Q | 余数 R | status |
|---|---|---|---|---|---|---|---|---|
| 1 | 0 | 1 | 1 / 0 | M / 1 | 0 | 0 | 0 | 0 |
| 2 | 1 | 0 | 1 / 0 | 1 / 0 | 0 | 0 | 0 | 1 |
| 3 | C | C | 2C / 0 | 0 / 0 | C² | 1 | 0 | 0 |
| 4 | 100 | 4 | 104 / 0 | 96 / 0 | 400 | 25 | 0 | 0 |
| 5 | 100 | 7 | 107 / 0 | 93 / 0 | 700 | 14 | 2 | 0 |
| 6 | M | 1 | 0 / 1 | M−1 / 0 | M | M | 0 | 0 |
| 7 | 2^992 | 1 | (2^992+1) / 0 | (2^992−1) / 0 | 2^992 | 2^992 | 0 | 0 |
| 8 | M | M | (M−1) / 1 | 0 / 0 | M² | 1 | 0 | 0 |
| 9 | 5 | 9 | 14 / 0 | (M−3) / 1 | 45 | 0 | 5 | 0 |
| 10 | 2^1023 | 3 | (2^1023+3) / 0 | (2^1023−3) / 0 | 2^1024+2^1023 | (2^1023−2)/3 | 2 | 0 |

表中 `status` 为除法状态；上述各组的 `mul1024` 均返回 0。乘积表达式展开为：`C² = 2^1400 + 123456789×2^701 + 15241578750190521`，`M² = 2^2048 − 2^1025 + 1`。

第 3、8、10 组用于检查超过 1024 位的乘积，第 1、2 组用于检查零乘积及全部输出字清零。不得只核对乘积的低 32 个字。

验收范围包括：普通运算、零、相等、全长进借位、加法溢出、减法下溢、零乘积、乘法跨字进位、完整 2048 位乘积、除零、最高位参与除法，以及调用约定和内存访问合法性。实现必须适用于定义域内的其他输入，不能仅针对上述测试编写。

测试程序可每次运行一组，也可自行组织批量测试。验收时须能依据提交说明切换测试输入、找到各项结果，并检查输入是否保持不变、寄存器及栈是否正确恢复。不要求输出特定的 PASS/FAIL 文本。

数值测试通过是必要条件；指令限制、调用约定、内存边界及算法效率仍需结合代码与调试记录评阅。

## 六、提交要求

提交一个压缩包，命名为 `学号_姓名_1024位整数实验.zip`，根目录包含：

| 必交文件 | 内容要求 |

实验报告须包括：

1. **基本信息**：学号、姓名、实验名称、实际使用的 RARS 版本与模式。
2. **数据与寄存器设计**：1024 位操作数的 32 字布局、2048 位乘积的 64 字布局、各函数的寄存器用途、栈帧及保存恢复方案。
3. **算法说明**：加减法进借位判定依据；乘法的部分积生成、移位累加与进位处理；除法处理流程、循环不变量及执行次数分析。
4. **运行与测试记录**：说明默认输入、切换用例的方法、各结果的内存标签或输出含义；逐项记录上述 10 组数据的实际和、差、积、商、余数及状态值，与预期值比较，并说明输入保持、寄存器及栈恢复的检查结果。存在失败项时如实记录。
5. **调试证据**：至少四段有文字解释的寄存器/内存截图或记录，分别展示跨字进位、跨字借位、乘法向高位传播的一次关键状态变化、除法的一次关键状态变化。
6. **总结**：遇到的问题、原因、修正方式及仍存在的不足。

提交包无需包含 RARS、Java 安装包或官方文档。截止时间及提交平台以教师课堂通知为准。
